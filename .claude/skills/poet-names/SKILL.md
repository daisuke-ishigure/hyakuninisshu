## 英語名

英語の歌人名・肩書きは `list_en.html` の表記に合わせる（例：43番 Middle Counselor Atsutada、64番 Middle Counselor Sadayori、66番 Senior High Priest Gyōson、73番 Acting Middle Counselor Masafusa）。日本語の歌人名を変えたら、対応する英語名も合わせて直す。

## 歌人名を変えるときの手順

歌人名はサイト全体に重複して書かれている。1か所だけ直さず、次をまとめて更新する。

1. 対象は HTML・`js/*.js`・`js/*.json`・`_tools/*.mjs`・`*.md`（`discon/` と `ai/` は除く）。`<ruby>名前<rt>読み</rt></ruby>` の読み、`data-yomi`、`nameKana` も合わせて直す。作者欄などでルビやツールチップの `<span>` が名前の途中に入っている箇所（例：`<ruby><span class="tippy …">中納言</span>敦忠<rt>…`）は文字列一致で見つからないので個別に探す。
2. 生成ページの元データ（`js/hyakunin.json`、`js/zukan.js` / `js/zukan_en.js`、相関図のデータと `js/keizu-tips*.js` など）を直し、ビルドで反映する（`node .claude/hooks/run-builds.mjs --all < /dev/null`。標準入力を閉じないと止まる）。
3. 編集した CSS/JS/JSON を読み込んでいるすべての HTML のキャッシュバスターを更新する（JS 内に JSON のバージョンが書かれている場合は、その JS を読み込む HTML も更新する）。
4. 最後に旧表記が `grep` で0件になったことを確認する。
